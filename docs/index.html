Seth Anandram Jaipuria School's Library Website

This document provides an overview of the Seth Anandram Jaipuria School Library Website, developed by Manav Kumar Mishra of Class VIII-D.

The website is a fully-featured, production-ready digital library ecosystem designed for students, teachers, and library administrators. It provides centralized access to the school library's catalogue, book details, reading progress tracking, achievements, leaderboards, physical book issuing, custom shelves, reading challenges, teacher management portals, and community discussions.

The website is built using modern web standards and public cloud services, allowing full platform operations, hosting, and backend data persistence within free usage tiers.

Purpose of the Website

The primary goal of the platform is to fully digitize, streamline, and gamify the school library experience for the entire student body and staff community.

Instead of maintaining physical registers or fragmented records, the platform integrates catalogue browsing, reading progress, achievement rewards, and administrative oversight into a cohesive web application.

The website accomplishes the following:

  • Provides instant, searchable access to the digital book catalogue with full book metadata.
  • Enables students to request physical book issues with automated return notices and fine policy disclaimers.
  • Tracks student reading progress page-by-page with interactive completion status bars.
  • Gamifies student reading through 16 unlockable achievements, live stat evaluations, and toast notifications.
  • Offers a 4-tab competitive Leaderboard for student engagement while strictly excluding staff to ensure fair play.
  • Enables personal reading list management with default shelves (Want to Read, Currently Reading, Favorites) and custom user shelves.
  • Fosters academic discussions via automated book-associated chatrooms with bad-word content filtering.
  • Provides a dedicated Teacher & Admin Dashboard for book issue approvals, reading challenge creation, student activity tracking, and announcements.
  • Enforces strict Security Enhancements including 72-hour email verification windows and instant multi-account switching.

Languages and Services Used

HTML5, CSS3 and Modern ES6+ JavaScript

The frontend is built using pure, highly optimized web standards:

  • HTML5: Semantic structure, accessible forms, modal dialogs, and dynamic page layouts.
  • Vanilla CSS3: Custom glassmorphic visual system, vibrant color tokens, responsive grid layouts, animations, and dark mode aesthetics.
  • ES6+ JavaScript (Modules): Asynchronous API calls, real-time achievement evaluation, client-side image compression, and dynamic DOM rendering.

Firebase (Google Cloud Platform)

Firebase powers the backend infrastructure without requiring physical server maintenance:

  • Firebase Authentication: User registration, login, 72-hour email verification gates, and Google OAuth single sign-on.
  • Cloud Firestore: NoSQL database storing user profiles, book catalogues, reviews, reading progress, shelves, reading challenges, book issues, and announcements.
  • Firebase Realtime Database: High-speed WebSocket messaging for discussion chatrooms and custom community threads.
  • Firebase Storage: Storage for compressed cover images, avatars, and direct PDF downloads (up to 100MB per file).
  • Security Rules: Fine-grained data access rules (`firestore.rules` and `database.rules.json`) enforcing role-based permissions and self-deletion rights for expired accounts.

GitHub & GitHub Pages

GitHub manages project source code, version history, and automated web deployment via GitHub Pages.

Website Structure & Page Modules

The application consists of specialized pages tailored for students, teachers, and administrators.

1. Home (`index.html`)

The portal landing page featuring quick navigation, featured book collections, recently added titles, library announcements, and platform stats.

2. Library Catalogue (`library.html`)

The main library catalogue supporting real-time genre filtering, title/author search, mandatory `totalPages` indicators, cover image displays, and book creation modals for staff.

3. Book Details (`book-details.html`)

A comprehensive detail view for every book. Includes plot summaries, character lists, setting details, themes, star ratings, review submission, direct PDF downloads, an interactive **Reading Progress Tracker**, a **"📋 Issue Book"** request button, an **"Add to Shelf"** manager, and personalized genre recommendations.

4. Student Dashboard (`student-dashboard.html`)

The personal hub for students. Displays reading stats (total pages read, finished books, reviews written), an interactive **"My Shelves"** widget, active **Reading Challenges**, a **Recently Viewed Books** carousel synced across devices, and a 16-badge **Achievements Grid** highlighting unlocked rewards.

5. Teacher & Admin Dashboard (`teacher-dashboard.html`)

A role-gated management portal reserved for staff (`role: teacher` or `admin`). Contains 5 tabs: Overview, Reading Challenges Manager, Book Issue Approvals, Student Activity Tracker, and System Announcements.

6. Leaderboard (`leaderboard.html`)

A 4-tab competitive showcase: Top Reviewers, Most Achievements, Most Books Read (ranking readers by finished books and pages), and Highest Rated Books. Staff accounts are automatically filtered out to focus competition on students.

7. Schedule (`schedule.html`)

A 6-Day x 8-Period Weekly Timetable portal. Allows students and staff to view the active weekly schedule across 8 periods (Period 1–8) and 6 days (Monday–Saturday) with class filters. Supports regular class periods, 🏖️ Holiday designations, and 🔄 Substitution coverage. Features click-to-edit for staff, automatic Sunday week rollovers, and a "📜 View Past Schedules" popup modal displaying historic weekly planners grouped by week range. All creation, edit, and deletion actions are recorded in the system Audit Log under the Schedule category.

8. Discussions (`discussions.html`)

Interactive community hub featuring book-specific chatrooms and user-created custom threads. Powered by Realtime Database with automated bad-word filtering.

9. Discover People (`discover.html`)

A student directory displaying member profiles, favorite genres, reading activity, and online status while keeping passwords and private data hidden.

10. Management Panel (`manage.html`)

Centralized administrative panel containing Catalogue CRUD, Issue Status columns (`Not Issued`, `Requested`, `Issued`), Review Moderation, Student Role Management, Analytics Charts, and Audit Logs with color-coded category badges.

11. Email Verification Gate (`verify-email.html`)

A security gate displaying a live **72-hour countdown timer** and resend options for newly registered unverified password accounts.

Security & Access Control

1. Role-Based Access Control (RBAC)

Strict role gating enforces user separation:

  • Students: Access library browsing, review submission, progress tracking, book issues, shelves, achievements, schedules, and student dashboards. Staff pages automatically redirect students to their dashboard.
  • Teachers & Admins: Access book management, review moderation, issue approvals, challenge management, timetable slot editing, student oversight, and audit logs.

2. Enforced 72-Hour Email Verification Gate

To enhance security and prevent spam or fake email signups, newly created password accounts must verify their email address within 72 hours of registration. If an account remains unverified after 72 hours, the system automatically purges both the Firestore user document and the Firebase Auth account.

3. Instant 1-Click Multi-Account Switcher

Users can sign into multiple accounts on a single device. The profile dropdown menu features a **"🔄 Switch account"** option placed directly above "Sign out". Clicking **Switch** on any saved account switches sessions instantly in the background without needing password re-entry or login redirects.

4. Client-Side Image Compression

Cover images and avatars are automatically compressed down to 600px max dimension (~30-50KB) before uploading to Cloud Storage, preventing network hangs and ensuring document sizes stay well below Firestore's 1MB limit.

Key Implemented Features

All core and advanced library features have been fully built and deployed:

  • Digital Book Catalogue: Full book metadata, SAJS-### auto-numbering, genre filters, and PDF attachment links.
  • 6x8 Weekly Timetable System: 6 Days x 8 Periods timetable grid with regular, 🏖️ Holiday, and 🔄 Substitution status badges, click-to-edit, auto-day calculation, automatic Sunday clearing, and a "View Past Schedules" historic planners popup modal.
  • Book Issue System: Request modal with overdue fine warnings, staff approval/rejection queue, and live Catalogue status column (`Not Issued`, `Requested`, `Issued`).
  • Interactive Reading Tracker: Page-by-page progress bars, mandatory `totalPages` field, and completion badges (`Not Started`, `Reading`, `Finished ✓`).
  • Reading Lists & Custom Shelves: Default shelves (Want to Read, Currently Reading, Favorites) and user-created custom shelves.
  • 16-Badge Achievement System: Live stat evaluation, real-time toast unlock popups, and student profile badges.
  • Student-Only Leaderboards: 4 rankings tabs excluding staff for fair student competition.
  • Teacher Management Portal: Dedicated dashboard for issue approvals, reading challenges, student activity, and announcements.
  • Instant Multi-Account Switcher: Device account registry with 1-click passwordless session switching.
  • 72-Hour Security Verification Gate: Mandatory email verification with live countdown timer and automated 72h account purge.
  • Community Discussions: Automated book threads with bad-word filtering and own-message alignment.
  • Audit Logging System: Full administrative audit logging with unified color-coded category badges (`Schedule`, `Book Issues`, `Announcements`, `Reviews`, `Users`, `Profile`, `Discussions`, `Reading Progress`).
